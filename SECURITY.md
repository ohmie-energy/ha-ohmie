# Security

Please report a vulnerability privately. Do not open a public issue.

- **Preferred:** GitHub → this repository → **Security** → **Report a vulnerability**.
- **E-mail:** security@ohmie.energy

Tell us the version, what you found and how to reproduce it. We reply as soon as we can.

In scope: this integration, and the Ohmie endpoints it uses (`auth.`, `api.` and
`events.ohmie.energy`). Do not test against homes or accounts that are not yours.
